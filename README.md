<h3 id="project1">Project 1: Smart Patient Token Managament System Using ESP32 and OLED Display</h3>
<p>
The Smart Patient Token System is an IoT-based healthcare solution that uses an ESP32, push button, OLED display, and web dashboard to automate patient queue management. Patients can generate tokens themselves, while hospital staff can manage the queue, recall missed patients, and monitor real-time updates through a synchronized web interface. The system's uniqueness lies in its low-cost design, wireless operation, self-service token generation, real-time synchronization, and missed-token recall feature, making it more efficient than traditional manual token systems. By reducing waiting time, minimizing crowding, improving hospital workflow, ensuring fair token allocation, and enhancing the overall patient experience, the system provides a practical and affordable solution for modern healthcare facilities and contributes to better public healthcare services. reduce to 350 characters
